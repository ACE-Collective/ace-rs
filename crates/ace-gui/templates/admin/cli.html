Administration

CLI

Runs an ACE command as ace <command> on a parser pool, contained like a task: no files, no network and no credentials, until it exits or its timeout runs out from when the pool takes it. Closing this page or signing out doesn't stop it. There's no terminal, so a command that prompts fails. Every run is recorded with who ran it and its output, and everyone who can use this page sees it.
